# Historical installation instructions

This page describes a superseded WeeWX/MQTTSubscribe combination. The maintained
catalog archive targets WeeWX 5.5–5.x. Follow the
[current installation and update guide](../readme.md) and use its fixed archive
URL. Its installed module is `user.mqttsubscribe`.

For older deployments, consult the original
[upstream historical instructions](https://github.com/weewx-mqtt/subscribe/blob/35068866003ab045dcf721fbccdd6dc82fb60b57/docs/reference/installing-and-updating-version-2.x-and-earlier.md).
Those instructions describe the old distribution, including old file names and
install-time environment variables. They do not apply to the catalog archive.
